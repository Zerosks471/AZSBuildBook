# Character saves (cross-PC)

Source on Windows: `%APPDATA%\wenilla-rogue\`

## Restore on another computer

1. Close Azeroth Survivors.
2. Copy the contents of `character-saves/wenilla-rogue/` into:
   `%APPDATA%\wenilla-rogue\`
   (create the folder if missing)
3. Launch the game and import/select your save if prompted.

Active character file: `characters.txt`
Slot backups: `Saves\*.sav`

Note: this folder is progress data. Prefer a **private** GitHub repo if you care about privacy.
